# Code Review

Use this skill when asked to review code, identify improvement opportunities, or look for defects.

Priorities:
- correctness and edge cases
- API safety and error handling
- maintainability and naming clarity
- performance implications
- security-sensitive misuse

Return findings in a clear priority order: high, medium, then low.
