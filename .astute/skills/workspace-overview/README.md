# Workspace Overview

Use this skill when the user wants a brief understanding of the current project, repositories, or workspace structure.

Focus on:
- the immediate goal and likely entry points
- the top-level project architecture
- important configuration files and conventions
- any unusual constraints or risks

Keep the summary concise, technical, and action-oriented.
