# Support

- Report a bug or ask for a feature in [GitHub Issues](https://github.com/Astute-Systems/astute-chat-vscode/issues).
- For commercial support, contact [Astute Systems](https://astutesys.com).

When you report a problem, include your VS Code and Ollama versions, the model you used, and the output of **Astute Code: Show Logs**. Check it for anything private first.
